# Homebrew Tap — Zeri

Homebrew formulae for [Zeri](https://github.com/ilmartotch/ZeriReplEngine), a TUI multi-language REPL.

## Install

```bash
brew install ilmartotch/zeri/zeri
```

Or add the tap first:

```bash
brew tap ilmartotch/zeri
brew install zeri
```

## Supported platforms

| OS    | Architecture | Status |
|-------|-------------|--------|
| macOS | arm64       | ✓      |
| Linux | amd64       | ✓      |

## Upgrade

```bash
brew upgrade zeri
```

## Uninstall

```bash
brew uninstall zeri
brew untap ilmartotch/zeri
```
